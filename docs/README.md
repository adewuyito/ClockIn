# StellarRep — Docs

Architecture, roadmap, and specs for [StellarRep](https://github.com/StellarRep/StellarRep) — a portable, on-chain reputation record for gig/freelance workers on Stellar.

Part of a multi-repo project: see [`StellarRep/StellarRep`](https://github.com/StellarRep/StellarRep) for overall project context, [`StellarRep/contracts`](https://github.com/StellarRep/contracts) for the Soroban contract, and [`StellarRep/app`](https://github.com/StellarRep/app) for the iOS client.

## Start here

- [`ROADMAP.md`](ROADMAP.md) — the phased build plan; "what do I do first."
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — system design, data flow, security posture, non-goals.
- [`CONTRACT_SPEC.md`](CONTRACT_SPEC.md) — the Soroban contract: storage, functions, errors, events.
- [`APP_SPEC.md`](APP_SPEC.md) — the Swift app: structure, screens, SDK usage.
